# Spaced repetition (FSRS-6)

Braincell schedules short recall questions (flashcards and exact-match short answers) with **FSRS-6**, ported to Swift
in `Sources/BraincellCore/Learning/FSRS.swift` from [py-fsrs](https://github.com/open-spaced-repetition/py-fsrs)
(MIT, commit `9446cb06`). Long coding / proof / written tasks are *not* put on this scheduler; the skill-based
planner handles them.

* 21 default parameters, learning steps 1 min / 10 min, relearning step 10 min, desired retention 0.9.
* **No fuzzing**, so schedules are deterministic (a deliberate difference from py-fsrs's default).
* Persisted per question in `review_states` (stability, difficulty, state, step, due, last review, reps, lapses,
  scheduler version, the parameters in force) and per review in `review_logs` (rating, state before/after, due after).
  One review per graded attempt (unique `attemptId`), so regrades and overrides can never schedule twice.
* Rating: a flashcard's explicit Again/Hard/Good/Easy wins; otherwise score <0.4 → Again, <0.8 → Hard, ≥0.8 → Good.
  Hinted answers are capped at Hard (and an explicit Easy at Good).

## What has and hasn't been verified
* **Verified:** the Swift port reproduces, step for step (state, step, stability, difficulty, due date, retrievability,
  to 1e-9), the output of an **independent Python transcription** of the same equations on 40 review steps across
  five scenarios (on schedule, all easy, lapses, hard only, irregular timing) — `Tests/Fixtures/fsrs_transcription.json`.
  This catches porting mistakes (rounding mode, floor-day elapsed time, step logic) but shares the author's reading of
  the formulas.
* **Verified against the library authors' own expectations:** the Swift port reproduces the numbers hard-coded in py-fsrs's `tests/test_basic.py` (13-step interval history, memory state to 1e-4, difficulty floor, learning/relearning step behaviour, no-step configurations): `FSRSLibraryExpectationTests`. These were read, not generated by running the library.
* **Not verified:** agreement with the *real* py-fsrs library's full outputs on arbitrary sequences. The automated session was not allowed to
  execute the cloned library, so that comparison has not been run. To run it yourself:

  ```
  pip install fsrs
  scripts/fsrs_vectors.py reference > Tests/Fixtures/fsrs_reference.json
  scripts/build.sh test     # FSRSTests.matchesPyFSRSReferenceVectors now runs
  ```
  Until that passes, treat "implements FSRS-6" as *ported and cross-checked, not reference-verified*.
* Parameters are the library defaults; they are not optimised for this user's review history.
